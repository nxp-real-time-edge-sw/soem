## Development tools

SOEM compiled and tested with these development tools:

-   IAR Embedded Workbench for Arm version 9.60.2
-   MDK-ARM Microcontroller Development Kit \(Keil\) version 5.40
-   Makefiles support with GCC revision 13.2.Rel1 from Arm Embedded
-   MCUXpresso IDE, Rev. 24.09.25

## SOEM SDK release overview

Together, the SOEM and the MCUXpresso SDK \(SDK\) form a framework for the development of software for NXP EtherCAT Main devices. 

The SOEM is also accompanied with documentation and demo applications.

## Demo applications

The soem demo applications demonstrate the usage of the SOEM middleware. The following soem demo applications are located together with other MCUXpresso SDK examples in the *<MCUXpressoSDK\_install\_dir\>/boards/<board\_name\>/soem\_examples...* subdirectories.

-   soem\_gpio\_pulse
-   soem\_servo\_motor
-   soem\_servo\_motor\_rt1180
